# 05 - Pengecualian terhadap Coding Guidelines

Tidak semua kode harus mengikuti aturan yang sama. Pengecualian harus:
1. memiliki alasan teknis,
2. dicatat,
3. diberi komentar di kode (jika menyimpang dari gaya umum).

## 1. Daftar Pengecualian

| ID | File/Area | Aturan yang dikecualikan | Alasan |
|---|---|---|---|
| EX-01 | `src/Inventory.Migrations.*` | Jangan edit generated code | Migration generated oleh EF |
| EX-02 | `docs/code-documentation/api/*.yml` | Format/style YAML | Generated DocFX |
| EX-03 | `Program.cs` | Top-level statements vs class | Gaya minimal host ASP.NET Core |
| EX-04 | `_ViewImports.cshtml`, Razor | Nullability `!` | Keterbatasan nullable pada view |
| EX-05 | `ApprovalGuard` internal static | Public API comments | Helper internal, bukan kontrak publik |
| EX-06 | `AppControllerBase` | Web tidak boleh refer EF | Transisi sampai `Inventory.Api` dipisah |
| EX-07 | `sql/postgresql/*` | Aturan C# | SQL bukan C#; aturan berbeda |
| EX-08 | `tests/*` | Naming/arrange | Test helper/dummy data |

## 2. Kriteria Pengecualian

- Generated code (tidak diedit manual).
- Interop/framework constraint.
- Alasan performa/keamanan terdokumentasi.
- Kode internal yang tidak diekspos.
- Transisi arsitektur dengan rencana perbaikan.

## 3. Pengecualian yang Tidak Diizinkan

- Menyembunyikan error dengan `catch { }` tanpa log.
- Menonaktifkan nullable secara global.
- Hardcode password/secret.
- Menonaktifkan test.
- Mengabaikan warning kritis tanpa alasan.

## 4. Contoh Komentar Pengecualian

### Generated migration
```csharp
// EX-01: Generated by EF Core migration. Do not edit manually.
```

### Transisi layering
```csharp
// EX-06: Temporary until Inventory.Api owns EF/transaction handling.
if (ex is DbUpdateConcurrencyException)
    return "Data telah berubah...";
```

### Razor null-forgiving
```cshtml
@* EX-04: Razor nullable analysis limitation; model validated by controller. *@
@Model.Title!
```

## 5. Review Berkala

- Pengecualian ditinjau setiap refactor besar.
- Jika alasan hilang, pengecualian dihapus.
- Pengecualian baru harus melalui code review.
