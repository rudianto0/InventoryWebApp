# Dokumentasi Kode Program

Dokumen ini menjelaskan identifikasi kode, dokumentasi modul, dokumentasi
method/fungsi/prosedur, serta cara menghasilkan dokumentasi API dari source
code aplikasi Inventory.

## Daftar Dokumen

| File | Butir |
|---|---|
| `01-identifikasi-kode.md` | 1. Identifikasi modul, parameter, algoritma, komentar kode |
| `02-dokumentasi-modul.md` | 2. Dokumentasi modul dan identitas |
| `03-dokumentasi-method.md` | 3. Dokumentasi method, fungsi, prosedur, eksepsi |
| `04-generate-dokumentasi.md` | 4. Tools dan generate dokumentasi |
| `04-annotated-code/` | Komentar baris demi baris untuk 7 modul inti |

## Prinsip

- Setiap modul memiliki ID unik (`MOD-*`) untuk pelacakan.
- Setiap method penting memiliki ID (`MTH-*`).
- Komentar baris demi baris tersedia untuk modul inti.
- Komentar XML dipakai untuk API reference.
- Dokumen direvisi bila kode berubah.
