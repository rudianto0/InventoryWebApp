# 1. Persiapkan dan Pasang Perangkat Lunak Aplikasi Data Deskripsi/SQL

## 1.1 Pasang perangkat lunak aplikasi SQL sesuai prosedur operasional standar

Database yang digunakan adalah **PostgreSQL**, dengan alat bantu **DBeaver**
sebagai aplikasi SQL untuk menjalankan perintah.

Langkah pemasangan:

1. Unduh installer resmi PostgreSQL.
2. Jalankan installer dan tentukan password administrator database.
3. Selesaikan proses instalasi.
4. Pastikan layanan database berjalan.
5. Pasang DBeaver sebagai alat untuk membuka dan menjalankan script SQL.

Catatan: password dan data sensitif tidak ditulis di dokumen ini.

## 1.2 Jalankan perangkat lunak aplikasi SQL

1. Buka DBeaver.
2. Buat koneksi baru ke PostgreSQL (host, port, dan user).
3. Klik **Test Connection** sampai berhasil.
4. Buka **SQL Editor**.
5. Jalankan script SQL sesuai urutan pada folder `sql/`.
