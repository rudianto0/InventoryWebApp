INVENTORY WEB APP - PETA ALUR PROSES PER FITUR
================================================

Catatan umum
------------
- FE saat ini adalah Razor View yang dirender di server, bukan SPA.
- Browser hanya mengirim HTTP request dan menerima HTML/CSS/JS.
- Semua akses data melalui Inventory.Client (in-process), lalu Application Service,
  lalu IAppDbContext/EF Core, lalu database.
- Audit otomatis, soft delete, dan concurrency ditangani di AppDbContext.SaveChangesAsync.
- POST memakai anti-forgery token dan pola POST -> Redirect -> GET.
- Diagram di bawah memakai Mermaid. Tempel ke viewer Mermaid jika ingin render visual.

```mermaid
    F --> H["DTO / PagedResult"]

```

0.2 POST CREATE / UPDATE
```mermaid
flowchart TD
    A["Browser submit form"] --> B["Controller.Create / Edit"]
    B --> C["Map ViewModel -> Input DTO"]
    C --> D["IClient.CreateAsync / UpdateAsync"]
    D --> E["InProcessClient"]
    E --> F["Application Service"]
    F --> G["Validasi + aturan bisnis"]
    G -->|valid| H["DbContext.Add/Update + SaveChangesAsync"]
    H --> I["AppDbContext: audit + soft delete"]
    I --> J[("Database")]
    J --> K["Response DTO"]
    K --> L["Redirect GET list/detail"]
    G -->|invalid| M["ValidationException -> ModelState"]
```

0.3 POST WORKFLOW TRANSAKSI (SUBMIT / APPROVE / REJECT)
```mermaid
flowchart TD
    A["Browser POST action"] --> B["Controller.Submit / Approve / Reject"]
    B --> C["IClient method"]
    C --> D["Transaction Service"]
    D --> E["ApprovalGuard / validasi status"]
    E -->|submit| F["Status = Submitted + Approver"]
    E -->|approve| G["Begin transaction"]
    G --> H["StockLedger.ApplyAsync"]
    H --> I["Update Stocks + Insert StockMovements"]
    I --> J["Status = Approved"]
    J --> K["SaveChangesAsync + AuditLogs"]
    E -->|reject| L["Status = Rejected + RejectionReason"]
    F --> K
    L --> K
    K --> M[("Database")]
```
